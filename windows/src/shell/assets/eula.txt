# 一、本软件是什么

ZXDesk 工作台 Windows 版（下称「本软件」）是一款桌面客户端：它把你自己搭建或经授权使用的 NAS / 服务器（例如飞牛 fnOS）的网页界面装进独立窗口，并提供访问码输入、两步验证、多地址管理、记住密码、开机自启、关闭到托盘、版本更新与公告等桌面能力。

本软件**不含服务端**，也不提供用于存放你业务数据的云服务。你的数据保存在你自己的服务器上，作者不运营存放这些数据的服务器，也无法访问它们。

# 四、你的数据在哪里

1. 你的偏好设置、会话信息、运行日志、公告缓存，以及选择「记住密码」时保存的登录口令，都保存在安装时选择的数据目录中（默认 `%LOCALAPPDATA%\ZXDesk\data`）。
2. 记住的登录口令使用 Windows 提供的加密存储（DPAPI）保护，不以明文写入磁盘，也不会出现在日志或诊断文本中。若当前 Windows 用户环境不支持该加密能力，本软件不会保存口令。

# 五、网络连接

本软件会在以下情形发起对外网络连接。除这些情形外，本软件不在后台发起其他对外连接。

1. **检查更新**：启动后自动向更新服务器请求一次版本信息（可在「设置 → 启动时检查更新」关闭）；你手动点「帮助 → 检查更新…」时也会请求。请求只携带运行平台（windows）与更新通道（stable / beta），不携带账号、密码、文件内容或设备标识。
2. **获取公告**：启动后请求一次公告内容（顶置公告与公告列表），用于菜单栏公告条与公告窗口。请求只携带运行平台标识。
3. **下载更新**：只有你点击「下载更新」时才会下载。本软件先向更新服务器取得下载地址，再访问 GitHub 或其公共加速镜像（如 ghfast.top、gh-proxy.com、ghproxy.net，具体以该版本下发的地址为准）。下载完成后按服务器下发的 SHA256 与安装包内版本号校验；校验不通过会删除文件并更换下载源，连续失败两次会停止，并提供百度网盘手动下载入口。
4. **打开网盘链接**：只有你点击「前往百度网盘下载」时，本软件才把该链接交给系统默认浏览器打开。
5. **连接你的服务器**：本软件访问你填写或扫描得到的服务器地址。你与该服务器之间的通信内容，以及该服务器记录的访问日志，由你或该服务器的管理者控制，不在本协议范围内。
