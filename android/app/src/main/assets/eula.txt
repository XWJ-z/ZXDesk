一、本软件是什么

ZXDesk 工作台 Android 版（下称「本软件」）是一款手机客户端：它把你自己搭建或经授权使用的 NAS / 服务器（例如飞牛 fnOS）的网页界面装进应用窗口，并提供连接管理、两步验证、访问码输入、登录保持、版本检测与更新等手机端能力。

本软件不含服务端，也不提供用于存放你业务数据的云服务。你的业务数据保存在你自己的服务器上，作者不运营存放这些数据的服务器，也无法访问它们。

四、你的数据在哪里

1. 手机上只保存连接所需的本机信息：服务器地址、飞牛账号名、是否优先使用 HTTPS、是否记住密码、已确认的设备证书指纹（TOFU），以及加密后的会话快照。
2. 选择「记住密码」时保存的登录口令使用 Android 提供的密钥库（Keystore）加密，不以明文写入磁盘，也不会出现在日志或诊断文本中。若当前设备的密钥库不可用，本软件不会保存口令。
3. 你的任务、笔记、密码库、账目等业务数据全部保存在你自己的服务器上，本软件不在手机上另存一份副本，也不上报使用统计、行为日志或崩溃报告，不包含第三方统计、推送或广告组件。
4. 卸载本软件会清除上述本机信息（含记住的口令）。服务器上的数据不受影响，仍可通过其它客户端访问。

五、网络连接

本软件会在以下情形发起对外网络连接。除这些情形外，本软件不在后台发起其他对外连接。

1. 连接你的服务器：访问你填写或扫描得到的地址。使用 FNID 中继时，会先经过飞牛官方门户（fnos.net）完成登录。你与该服务器之间的通信内容，以及该服务器记录的访问日志，由你或该服务器的管理者控制，不在本协议范围内。
2. 检查更新：进入应用后自动向更新服务器请求一次版本信息；你手动点「检查更新」时也会请求。请求只携带运行平台（android）与更新通道（stable / beta），不携带账号、密码、文件内容或设备标识。
3. 下载更新：只有你点击「下载更新」时才会下载。本软件先向更新服务器取得下载地址，再访问 GitHub 或其公共加速镜像（如 ghfast.top、gh-proxy.com、ghproxy.net，具体以该版本下发的地址为准）。下载完成后按服务器下发的 SHA256 与安装包内版本号校验；校验不通过会删除文件并更换下载源，连续失败两次会停止，并提供百度网盘手动下载入口。
4. 打开外部链接：只有你点击「前往百度网盘下载」或应用内明确的外部链接时，本软件才把该链接交给系统浏览器打开。
